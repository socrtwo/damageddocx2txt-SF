Damaged DOCX to Text — Linux
============================

How to run
----------
1. Extract: `tar -xzf damageddocx2txt-linux.tar.gz`
2. Run:    `./damageddocx2txt.sh`
   - The script opens `web/index.html` in your default browser via xdg-open.
   - You can also open `web/index.html` manually.

Optional: install as a desktop app
----------------------------------
With the page open in Google Chrome or Chromium, click the install icon in
the address bar (or "Install Damaged DOCX to Text..." in the menu) to add it
to your application launcher and run it offline.

Privacy
-------
Your .docx file never leaves your computer; all processing happens locally
in the browser.
