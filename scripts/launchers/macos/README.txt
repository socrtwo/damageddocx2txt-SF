Damaged DOCX to Text — macOS
============================

How to run
----------
1. Unzip this archive anywhere (e.g., your Desktop).
2. Double-click `DamagedDocx2Txt.command` to open the app in your default browser.
   - macOS may warn that the file is from an unidentified developer the first
     time. Right-click the file and choose "Open" to bypass that prompt.
   - Or just open `web/index.html` directly.

Optional: install as a desktop app
----------------------------------
With the page open in Google Chrome or Edge, choose
  File -> Install Damaged DOCX to Text
to get a standalone Dock app that works offline.
Safari does not currently support installing arbitrary PWAs as apps.

Privacy
-------
Your .docx file never leaves your Mac; all processing happens locally in the
browser.
