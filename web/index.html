How it works

A .docx file is a ZIP archive of XML parts. When it's damaged, this tool tries three strategies in order:

  1. Standard ZIP read — opens the archive and validates each entry.
  2. Low-level scan — when the central directory is broken, scans the byte stream for ZIP local-file headers and reconstructs entries one by one.
  3. XML repair & text rescue — fixes truncated or malformed XML, then pulls the text of every paragraph from word/document.xml (and headers/footers/notes) — bypassing Word's strict validation.

The primary output is a clean .txt. A best-effort repaired .docx is also offered, rebuilt as a fresh, well-formed package.
